# 企画メモ：札の家 ― 奥の棚の櫛

2026-11-15 作成。game-kit の [作る順番](https://github.com/hashito/game-kit/blob/main/docs/build-order.md) の S0。作者の案（おばけ屋敷・奥の棚から櫛を持って来いと脅される・お札が貼ってある家の謎を解いて終わる・地下室と長い地下通路・屋外なし）から、残りを設計した。

## 1. 一行で

- 題名（決定）／英題：札の家 ― 奥の棚の櫛 ／ Fuda no Ie: The Comb on the Back Shelf
- 一行の売り（site.json の description の元。50〜200字）：訪問介護のヘルパー宮下航は、代わりに訪ねた古い櫛屋の町家に閉じ込められる。帳場の格子の奥から、家の主のハルが言う。「奥の棚から、櫛を持って来い。持って来るまで、表の戸は開けん」。家じゅうの戸に貼られたお札をはがして奥へ進み、地下の室と封じられた部屋の奥で、五十二年前にこの家で起きたことを知る一人称3Dホラー。
- 題材・元になった話：オリジナル。「櫛は苦死に通じるので贈り物にしない」という言い伝え（実在の俗信）と、柘植櫛（つげぐし）の作り方（板を燻して何年も室で寝かせる）を使う。実在の家・人・事件とは関係しない。

## テイスト

- テイスト: standard（写実寄りの暗い町家。土間・格子・板の間。白い札と赤い印だけが目に立つ）

## 2. 主人公と目的

- 主人公は誰か・職業・年齢：宮下 航（みやした わたる）、24歳。訪問介護のヘルパー（二年目）。今日は熱を出した先輩の野口さんの代わりに、初めてこの家に来た。利用者の櫛田ハル（96）とは初対面。家の昔のことは何も知らない。
- なぜここに来たか・なぜ帰らないか（K-03）：事業所の予定表に「17:30 櫛田様 訪問」とあったので、鍵箱の番号で戸を開けて入った。入ったとたんに表の戸がひとりでに閉まり、押しても引いても動かなくなる。帳場の格子の奥からハルが「戸はわしが押さえとる。奥の棚の櫛を持って来るまで、開けん」と言う。携帯は圏外。逃げ道がないので、言われたとおりにするしかない。
- 最後に理解すること／達成すること：(1) ハルは先週、病院で亡くなっている（途中で家の黒電話に野口さんから電話が来て分かる）。死んだ者はお札を越えられないので、ハルは自分の貼った札の輪から出られない。だから生きている私に取りに行かせた。(2) 嫁の千草は昭和49年に「家出した」ことになっているが、本当は、ハルに「奥の棚から櫛を持って来い」と言われて地下へ降り、揚げ戸に上から札を貼られ、臼で押さえられて、地下の奥で亡くなった。(3) ハルが櫛を欲しがるのは、燃やして千草を消すため。最後に、櫛をハルに渡すか、千草に返すかを選ぶ。
- 最初から持っている道具（I-01）：訪問の記録票（利用者の情報と注意書き）、携帯（圏外、電池が少ない）。走り庭で手燭とマッチを持つ。

## お札と櫛の決まり（A15：一文で）

**この家のお札は、死んだ者を通さない。千草さんは、自分の櫛のある所へ来る。**

- はがす：札の貼られた戸は、札を [E] でそっとはがすと開く。はがした札は持ち歩ける（右上に「札 ×N」）。
- 貼る：持っている札は、戸の柱や煙道の口に [E] で貼れる（重ねて貼れる）。貼った札の向こうへ、死んだ者は来られない。ただし強く押されると札は黒く焦げ、しばらくで落ちる（焦げていく様子と残りの時間が見える）。
- 櫛：千草さんは、清次さんの櫛のある所へ来る（ハルの「札の控え」）。作りかけの櫛を置けばそこへ、婚礼の櫛を持てば持った者のところへ。地下の部屋は煙道でもつながっていて、死んだ者は煙道を這って通る。
- 生きている者は、札のある柱も通れる（札がふさぐのは死んだ者だけ）。戸が開かないのは、札が戸と柱にまたがって貼ってあるから（はがせば開く）。
- 表の戸は、家の主のハルが押さえている。ハルが手を離すまで開かない（これは決まりではなく、ハル自身がそう言う。最後に開く）。

## 5. 怖さ・手応え

- 怪異のルール：千草さん（藍の着物、膝まである濡れた黒髪で顔が見えない）は、櫛を持った者を追う。触れられると地下へ引き込まれて死ぬ（直前の記録から）。柱に札を貼ると、その柱の向こうで止まる（札は焦げて、しばらくで落ちる）。札を貼った戸棚に隠れると、櫛の気配が消えて見失う。
- 最初の遭遇は教える場面（E-01）：通路の札の回廊で、格子戸の向こうに千草さんが現れ、格子に貼られた札に押し返される（届かない）。そのすぐ先で、ハルに教わったとおり柱に札を貼ると、迫ってきた千草さんが柱の向こうで止まる（練習。失敗しても死なない）。本番は櫛を取ったあと。
- 手応えのある判断・操作：札の数の管理（はがした札が、帰りに使える札）。どの柱で貼るか（低い道・水の道は遅くなるので、その手前で貼る）。櫛の箱の紐をほどく（trace-path・糸）、臼を梃子で動かす（timing）、灯明の火を守って移す（steady-hand）、ハルの手紙を日付の順に並べる（order-steps）。最後の謎解き（作業台で、集めた物を根拠に四つの問いに答える）。

## 2.0 地下の作り直し（2026-11-20、ユーザー指摘 #16）

水無瀬病院（水・止水弁・追跡トンネル・這う区間・ロッカー）と遊びが重なっていたので、地下を全部作り直した。長い通路・水の道・低い道・札の回廊・結界の柱・戸棚・灯明はなくした。

- 部屋：室（はしご・燻し炉・札の控え・呼び鈴の紐）→ 土の廊下（天井に鈴の紐）→ 板の間（寄り道：壁の札三枚）／燻しの間（干し棚・煙道の口）→ 格子戸 → 奥の室（棚の櫛の箱・千草さんの亡きがら・もう一つの煙道の口）。
- 遊び：札をはがす・貼る・重ねる、火（手燭で蝋をとかす。消えたらマッチで入れ直す）、櫛（作りかけの櫛で千草さんを呼び寄せる）、家の秘密（札の控え：ハルが降りて封じた記録）。追いかけっこではなく「どこに札を貼って、千草さんをどこへ動かすか」。
- 千草さんの道：部屋の間の戸と、燻しの間と奥の室を結ぶ煙道（見えない。鈴の音で居場所が分かる）。貼った札は、櫛を持ったあとだけ押されて、端から少しずつ黒く焦げて落ちる（約22秒／枚、おだやか設定38秒）。
- つかまったら：その場面の始めに戻る（燻しの間：煙道の札が元に戻り、千草さんは奥の室へ。櫛のあと：櫛を取った直後の札の数で、棚の前から）。続きから始めても同じ。
- 主人公が同じことをする（櫛でおびき寄せて閉じこめる）のは、ハルが五十二年前にしたことの繰り返し。結末の選択の重さにつなげる。
