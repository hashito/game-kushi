# game-kit へのメモ（札の家で困ったこと）

2026-11-15、game-kit 0641622 で作った。kit は変えていない（ここに書くだけ）。

1. **smoke が遊べない**：smoke は作業ごとに「その場所の箱」を押すが、この作品は箱のない作業（部屋に入ると終わる T_ESCAPE、作業台の選択）があり、途中で止まる。また 2 階建ての計画（家が floor 1、地下が floor 0）で、始まりの位置が floor 1 だと「部屋の中で始まる」の確認が外れる。通しの確認は `tools/play/full.mjs`（実際のキー入力で三つの結末まで）で行った。
2. **check:traps と「しゃがんで通る梁」**：低い道（P2）の梁は、立っていると当たり、しゃがむと通れる（ext の `fp.solid` を上書き）。check:traps は体の高さ 0.15〜1.6 m の当たりをすべて壁とみなすので、P2 が閉じた所になり、室・板の道の戸棚と箱が「本道にない」と出る。当たりに `low: true` を付けたものは「しゃがめば通れる」と扱えるとよい。
3. **?qa=1 の `ctx.choose`**：何も開かず `window.__gfChoice` か primary を返す。四問を続けて答える作業台のような場面では、一つの値では足りないので、通しの確認では getter で順に返す列を使った（full.mjs の `pre()`）。kit 側で「答えの列」を受け取れるとよい。
4. **はしご（ST_HATCH）の [E] の箱**：作業場の床の揚げ戸の真上に、はしごの箱が重なる。揚げ戸の作業のあいだ、はしごの箱を interactables から外して避けた。
5. **InstancedMesh** は `frustumCulled = false` にしないと、札の壁が見る向きで消えた。
