# 札の家 ― 奥の棚の櫛：仕様レビュー（β）

2026-11-15。game-kit 0641622 から作った新作（key `kushi`）。作者の案：おばけ屋敷／奥の棚から櫛を持って来いと脅される／お札が貼ってある家の謎を解いて終わる／地下室と長い地下通路／屋外なし。

## 1. 一文の決まり（A15）

**この家のお札は、死んだ者を通さない。千草さんは、自分の櫛のある所へ来る。**

- 戸の札をはがすと戸が開き、札は手もとに残る（右上「札 ×N」）。
- 持っている札は、通路の「結界の柱」に貼れる。柱の向こうで千草さんは止まり、札は焦げて（残りが見える）落ちる。
- 札を貼った戸棚に隠れると、櫛の気配が消えて見失われる。
- 帳場の格子にもハルが貼った札がある。死んだハル自身が、その輪から出られない（だから生きている「私」に取りに行かせる）。

kagamiya（鏡に映るかどうか・カメラ）とは仕組みが別：資源（札）を取る行為（はがす）が道を開け、使う行為（貼る）が身を守る。行きで何枚はがしたかが帰りの余裕になる。

## 2. 段階と時間（自動プレイの実測）

| 段階 | 内容 | 時間（自動プレイ） |
|---|---|---|
| L1 帳場の声 | ハルの話、大黒柱で「貼る・はがす」の練習 | 約20秒（人なら3〜5分） |
| L2 家の奥へ | 中の間・走り庭・奥の間・作業場。黒電話（野口さん）、臼（timing）、揚げ戸 | 約45秒（人なら8〜12分） |
| L3 室と長い通路 | 手燭（steady-hand）、灯明4つ、札の回廊、格子戸の千草さん、柱の練習、奥の室 | 約110秒 |
| L4 櫛と追跡 | 箱の紐（trace-path）、追われて戻る、揚げ戸に札（10秒の押し合い） | 約70秒 |
| L5 謎 | 作業台で四つの問い、櫛をどうするか、結末3つ | 約40秒 |

- **通路を歩く時間：103秒**（室の板戸から奥の室の扉まで、歩きのみ。目標90秒以上）。約10秒ごとに出来事 e1〜e14（髪をすく音、挟まった髪、火が倒れる、板が崩れる、低い天井、濡れた手の跡、横切る影、水、水音、浮いた髪、鼻歌、札のざわめき、素足の跡、近い髪すき）。
- 人が遊ぶ目安：30〜45分。

## 3. 冷たい読み手テスト（別の読み手に、文章だけを渡して答えてもらった）

問い：誰の話か／今どういう状態か／本当か／それは何か／だから何か／なぜか（A14〜A19）。

読み手が答えられたこと：主人公（ヘルパーの宮下航）、閉じ込められた理由（ハルが戸を押さえる）、目的（奥の棚の櫛）、ハルが死んでいること（黒電話）、千草さんに起きたこと（揚げ戸に上から札）、ハルが櫛を欲しがる理由（燃やして千草さんを消す）。

読み手が引っかかった点と直したこと：

| 指摘 | 直したこと |
|---|---|
| 死んだハルが戸を押さえ、格子から手を伸ばすのは、札の決まりと矛盾 | 「戸を押さえるくらいはできても、札の外へは一歩も出られん」をハルの台詞に。櫛は自分で格子のすき間から差し入れ、火鉢に落ちる形に |
| 格子の札の向き（内から外）が意味不明 | 「外から何かが入らないように、貼ったのだろうか」に。真相（自分を閉じこめた）は終盤で |
| 戸棚の札の説明がない | 柱の練習の直後に「戸棚の扉の内側にも札。隠れれば見えなくなるかも」 |
| 火鉢が初出で唐突 | 帳場の説明で「内には、火鉢と小さな行灯」 |
| 五十年／五十二年の混在、清次の死んだ日、手紙の数 | すべて五十二年。清次は「十月（日記・位牌）」。「三通の封筒に、四枚の手紙」 |
| 家出の選択肢の「男の人と」、寺の人の選択肢が根拠なし | 「家出して、遠くへ行った」。寺の人→「千草さん自身」（上から札なので不可、と理由） |
| 問4の理由が後の真相を先に漏らす | ハルの台詞と「苦死」から推せる理由に差し替え |
| E3（札をはがす）の意味が選ぶ前に分からない | 選ぶ画面に「格子の外へ出て、千草さんに謝りに行ける。もう、ここには残らない」。手紙を読んでいなければ、まだ分からないと出す |
| 読めない語 | 帳場（店の勘定場）、揚げ戸（床にはめた戸）、室（むろ）、灯明（とうみょう：油の皿の灯り）、柘植（つげ）、梃子（てこ）、苦死（くし） |
| 方言の混在（やない） | 「じゃない」に統一（ハルだけが「〜ん」「〜とる」） |

二回目の読み手：§7 を参照。

## 4. 監督の講評（怖さ・案内・テンポ・見返り）

- **怖さ**：良い。千草さんが最初に見えるのは格子戸の向こう（届かない＝安全）、次が柱の練習（死なない）、本番は櫛を取ってから、と三段で近づく。通路は手燭の火だけで、灯した灯明が追跡中に千草さんが通るたびに消え、帰り道が後ろから暗くなる。弱い点：通路の前半（板の道）は出来事が音と文字に寄っていて、目に見えるものが少ない。髪・手の跡は置いたが、もう一つ「見える」物（例：遠くで消える手燭の火）があると良い。
- **案内**：左上の目標と STEP、札の数（右上）、柱は「結界の柱」と名前が出る。最初の柱の練習は失敗しても死なない。戸棚は「札を貼った戸棚」と書き、通路に4つ。迷いやすいのは揚げ戸の臼（梃子を先に取る）だが、臼に向くと「作業場の東の壁に梃子」と言う。
- **テンポ**：家（L1〜L2）は短めで、通路（L3）で一度ゆっくりにし、L4 で一気に走らせる。揚げ戸の押し合い（10秒）が最後の山。L5 の謎は四問の選択で、間違えると理由が出て選び直し。
- **見返り**：結末が3つ。E1（言われたとおり燃やす）は「何も知らずに従った」苦い終わり、E2 は千草さんが見つかる、E3 は手紙（寄り道）を読んだ人だけがハルも解く。札をはがしてきた行為が、最後に「ハルの札をはがす」選択と同じ動作で重なる。
- **気になる点（次の版で）**：自動プレイでしか通していない区間がある（§6）。追跡の難しさは人の手で調整が要る（今は千草さん 3.0 m/s、低い道 0.36 倍、水 0.58 倍、7秒ごとの小さな踏み込み。やさしい設定で 0.8 倍）。

## 5. 処理の重さ（headless Edge・ソフトウェア描画での実測）

- 遊んでいる間：p50 17.4 ms、p95 18.2〜18.6 ms（3秒以降）。はしごで階を移っても最大 19 ms（シェーダーの作り直しなし。プログラム数 22 のまま）。
- 始めた直後に一度だけ、約5秒の停止（シェーダー12本の仕上げ。開始時に先に作ったものを GPU が仕上げる待ち）。冒頭の会話の窓が出ている間に起きる。ソフトウェア描画（SwiftShader）なので実機の GPU ではずっと短いはずだが、実機では測っていない。
- 千草さんの冷たい光は最初から場面に置き（強さ 0）、出るときに強さだけを上げる（光の数が変わらないので作り直しが起きない）。
- 手燭の明かりは壁が近いと弱まる（1秒に8回、正面を調べる）。近い壁が白く飛ぶのを防ぐため。

## 7. 二回目の読み手（文章だけを渡した別の読み手）

一回目の直しのあと、もう一度、文章だけで読んでもらった。直したこと：

- 回廊の札の日付が「昭和四十九年より後」→揚げ戸が封じられていたので矛盾。「昭和四十九年霜月十四日」の一晩で貼った、に。
- 年齢：ハル九十六歳と清次（行年二十九）で計算が合わない→清次を行年二十六に。
- ハルの動機が二つ（燃やして消す／同じ側へ行くのが怖い）→「燃やせば、あの子は消える。消えれば、会わずにすむ」で一つに。
- 箱の紐がほどけないなら箱ごと持てる→「棚の柱に固い紐で縛りつけてある」。
- 戸棚に隠れる理由→「千草さんは、櫛を探してくる。……櫛ごと見えなくなるかもしれない」。
- 奥の室で答えを言い切っていた→「……千草さん、なのか」で止める（問1が自明にならないように）。
- 読み仮名：手燭・燻し炉・行灯・行年・結界・白無垢・帯留め・水屋（初めて出る所）。
- 長い台詞（ハルの「わしは先週、死んだ」）を三つに分けた。櫛を火鉢へ落とすのはハルの手（格子の内側）に。
- 結末：E1「私は、地下のことを誰にも言えなかった」、E2「ハルさんは、今もあの格子の内で、背中を向けているのだろう」、E3 は野口さんに話したことを入れた。
- 手紙（三）が二枚入っていることを書いた（三通・四枚の理由）。

直していない指摘：手紙の本文は「並べる」画面に四通とも出ている（読み手に渡した文には入っていなかった）。湿った着物・水音の描写は、怪異の気配として残した。
